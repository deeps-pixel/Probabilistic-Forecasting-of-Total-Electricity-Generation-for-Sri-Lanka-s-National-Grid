Scenario Simulator

Run hypothetical grid events and simulate RL battery dispatch policies.

How it works

1. Define Target Date: The system forecasts the baseline load for the selected day.
2. Set Battery Constraints: Adjust the storage capacity and the max charge/discharge rates to model different BESS (Battery Energy Storage Systems) units.
3. Run AI Dispatch: The Reinforcement Learning agent computes the optimal charge/discharge cycles. The original curve is the base grid demand. The net load curve shows the demand after the battery operation. Positive battery dispatch implies discharging to the grid (shaving peaks), and negative implies charging from the grid (filling troughs).
